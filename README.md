# 音礼

在 Windows 双击 `启动音礼网站.bat`，或在本目录运行 `node server.cjs`，再打开 `http://localhost:4173/`。请保持服务窗口运行。直接双击 `index.html` 可浏览和本机预览，但不能生成可供其他设备打开的礼物链接。

首次打开会显示创作者与观看者教程。选择「创作一份记忆」，指定赠送对象后进入空白世界树；在镜中上传影像，在底部时间线加入音乐、字幕并编辑片段，最后完成礼物。收礼者通过礼物链接进入只读世界，可持续播放、点击树上照片在玻璃中观看、拖动底部进度条，并决定是否保存到自己的世界。档案胶片显示世界保存时的主场景截图，点击胶片直接回到对应世界。

创作者可在顶部切换世界树、街道、银河和山与湖泊；街道粒子由提供的 FBX 提取，其余新增场景由程序生成。一次选中多张图片会分别悬挂成多面镜子，赠送后保留镜子数量和位置。QQ 音乐好友入口是**本机演示**：可以切换演示身份、模拟发送音礼及留下文字或语音回声，但不会连接腾讯账号，也不会真正向好友发送消息。

创作资源与项目保存在浏览器 IndexedDB。运行本地服务时，已发布礼物及素材保存在 `.yinli-data/gifts/`。不要删除这些数据；更换浏览器、地址或设备时，本机草稿不会自动同步。通过 `localhost` 打开的链接只在当前设备有效；跨设备访问需要为服务配置可访问的域名、HTTPS 和部署环境。

## 上线

推荐将本仓库导入 Render Blueprint，配置文件 `render.yaml` 会创建 Node 网站和 1 GB 持久磁盘。磁盘是付费功能；确认费用后再在 Render 控制台创建服务。部署成功后使用 Render 提供的 HTTPS 地址，发布的礼物链接即可跨设备打开。不要把 `.yinli-data/`、本机素材、测试截图或示例商业音乐上传到 GitHub。

`YINLI_DATA_DIR` 必须指向持久磁盘挂载路径。服务有单素材 200 MB、单礼物总素材 500 MB 的上限；已发布礼物不可覆盖。当前没有账户系统，知道链接的人都能打开该礼物。浏览器中的创作草稿、个人世界和接收者收藏仍保存在各自设备的 IndexedDB 中，不会跨设备同步。

GitHub Pages 只提供静态页面：同一浏览器可以创建、保存并再次打开本机记忆，但无法承载跨设备的图片、视频和音乐礼物。不要把 Pages 上显示的本机预览码当成可分享链接。

如需启用静态预览，在仓库 `Settings → Pages → Build and deployment → Source` 选择 `GitHub Actions`，随后在 Actions 中重新运行 `Deploy static preview`。网站将发布在 `https://aobitou.github.io/Yinli/`。这个地址的本机预览码只在同一浏览器的同一网址下有效。
